# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Beta    | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities via:
1. **GitHub Security Tab** (preferred): [Private vulnerability reporting](https://github.com/TomSOhm/invest/security/advisories/new)
2. **Email**: Contact the maintainers directly

### What to Include
- Description of the vulnerability
- Steps to reproduce
- Potential impact assessment
- Suggested fix (if available)

### Response Timeline
- **Acknowledgment**: Within 48 hours
- **Initial Assessment**: Within 5 business days
- **Resolution**: Critical issues prioritized

### Disclosure Policy
- Do not publicly disclose until a fix is released
- Responsible disclosure will be credited

Thank you for helping keep this project secure.
