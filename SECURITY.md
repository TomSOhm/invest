# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security bugs seriously. Thank you for improving the security of this project.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via:

1. [GitHub Security Advisories](https://github.com/TomSOhm/invest/security/advisories/new) (preferred)
2. The GitHub Security tab's private vulnerability reporting feature

### What to Include

- Type of issue (e.g., buffer overflow, SQL injection, cross-site scripting, etc.)
- Full paths of source file(s) related to the issue
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce
- Proof-of-concept or exploit code (if possible)
- Impact of the issue

### Response Timeline

- We will acknowledge receipt within 48 hours
- We will provide an estimated timeline for a fix
- We will notify you when the issue is resolved

Thank you for helping keep this project secure.
